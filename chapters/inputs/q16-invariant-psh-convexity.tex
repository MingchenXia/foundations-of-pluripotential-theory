\subsection{Invariant functions on tubes and complex tori}
\label{sec:invariant-psh-convexity}
We now prove the correspondence between invariant plurisubharmonic functions and convex functions described at the beginning of the chapter. For a nonempty open convex set $V\subset\mathbb R^n$, $n\geq1$, consider the tube
\[
 V+\mathrm i\mathbb R^n=\{t+\mathrm is:t\in V,\ s\in\mathbb R^n\}\subset\mathbb C^n,
\]
with coordinates $w=t+\mathrm is$. Recall from \cref{sec:kiselman-minimum}, here without the variables $z$, that a function $U$ on the tube is invariant under imaginary translations if $U(w+\mathrm is')=U(w)$ for all $s'\in\mathbb R^n$, that is, if $U(t+\mathrm is)$ depends only on $t$. As observed there, the complex Hessian of a smooth function of this kind is a quarter of its real Hessian in $t$, so plurisubharmonicity becomes convexity; the general case follows by smoothing. The only additional point is that the value $-\infty$ cannot occur, which follows from local integrability.

\begin{proposition}\label{prop:invariant-psh-convexity}
Let $n\geq1$, let $V\subset\mathbb R^n$ be a nonempty open convex set, and let $U\in\PSH(V+\mathrm i\mathbb R^n)$ be invariant under imaginary translations. Then there is a finite convex function $f\colon V\to\mathbb R$ such that $U(t+\mathrm is)=f(t)$ for all $t\in V$ and $s\in\mathbb R^n$. Conversely, for every finite convex function $f$ on $V$, the function $f(\Real w)$ is plurisubharmonic on $V+\mathrm i\mathbb R^n$ and invariant under imaginary translations.
\end{proposition}
\begin{proof}
Define $f(t)=U(t)$, identifying $t\in V$ with $t+\mathrm i0$; by invariance, $U(t+\mathrm is)=f(t)$. By \cref{thm:psh-distribution-representative}, $U$ is locally integrable, so the set $\{U=-\infty\}=\{f=-\infty\}+\mathrm i\mathbb R^n$ is a Lebesgue null set in $\mathbb C^n$. Applying Fubini's theorem on products of compact boxes in $t$ and in $s$, we see that $\{f=-\infty\}$ is a null set in $V$.

For $\varepsilon>0$ let $V_\varepsilon=\{t\in V:\operatorname{dist}(t,\mathbb R^n\setminus V)>\varepsilon\}$. A point $t$ lies in $V_\varepsilon$ if and only if the closed ball $\overline{B(t,\varepsilon)}$ lies in $V$, so $V_\varepsilon$ is the intersection of the convex sets $V-y$, $|y|\leq\varepsilon$, and is convex. The points of the tube at distance more than $\varepsilon$ from its complement form the tube $V_\varepsilon+\mathrm i\mathbb R^n$. On this set let $U_\varepsilon=U*\rho_\varepsilon$, where $\rho_\varepsilon$ is the radial mollifier of \cref{sec:convolution} on $\mathbb C^n=\mathbb R^{2n}$. The function $U_\varepsilon$ is smooth, and its complex Hessian matrix $(\partial^2U_\varepsilon/\partial w_j\partial\bar w_k)$ is positive semidefinite. Indeed, for $\xi\in\mathbb C^n$, the function $\sum_{j,k}(\partial^2U_\varepsilon/\partial w_j\partial\bar w_k)\xi_j\bar\xi_k$ is, by \cref{prop:distribution-smoothing}(1), the mollification of the distribution $\sum_{j,k}(\partial^2U/\partial w_j\partial\bar w_k)\xi_j\bar\xi_k$, which is positive by \cref{thm:psh-distribution-representative} and the matrix criterion of \cref{sec:local-complex-potentials}, so it is nonnegative by \cref{prop:distribution-smoothing}(3).

Moreover, $U_\varepsilon\downarrow U$ as $\varepsilon\downarrow0$ by \eqref{eq:canonical-subharmonic}, because $U$ is subharmonic and locally integrable (\cref{thm:psh-distribution-representative}). Since imaginary translations commute with convolution, $U_\varepsilon$ is invariant under them; write $U_\varepsilon(t+\mathrm is)=f_\varepsilon(t)$. For a function of $t=\Real w$ alone we have $\partial/\partial w_j=\frac12\partial/\partial t_j=\partial/\partial\bar w_j$, hence
\[
 \frac{\partial^2U_\varepsilon}{\partial w_j\partial\bar w_k}
             =\frac14\frac{\partial^2f_\varepsilon}{\partial t_j\partial t_k}.
\]
The left side is a positive semidefinite matrix, so $f_\varepsilon$ has positive semidefinite real Hessian. Hence the restriction of $f_\varepsilon$ to every segment in the convex set $V_\varepsilon$ has nonnegative second derivative, and $f_\varepsilon$ is convex on $V_\varepsilon$.

Suppose that $f(t_0)=-\infty$ for some $t_0\in V$, and choose $r\in(0,1)$ with $\overline{B(t_0,3r)}\subset V$. The upper semicontinuous function $U$ is bounded above, say by $C$, on the compact set $\overline{B(t_0,3r)}+\mathrm i[-1,1]^n$. Since $U_\varepsilon(w)$ is an average of $U$ over the ball $\overline{B(w,\varepsilon)}$, we get $U_\varepsilon\leq C$ on $B(t_0,2r)$ for $\varepsilon<r$; moreover $B(t_0,2r)\subset V_\varepsilon$ for such $\varepsilon$. For $t\in B(t_0,r)$, the point $2t-t_0$ lies in $B(t_0,2r)$, and $t$ is the midpoint of $t_0$ and $2t-t_0$. Convexity of $f_\varepsilon$ therefore gives
\[
 f_\varepsilon(t)
   \leq\tfrac12f_\varepsilon(t_0)
                     +\tfrac12f_\varepsilon(2t-t_0)
   \leq\tfrac12f_\varepsilon(t_0)+\tfrac12C.
\]
As $\varepsilon\downarrow0$, $f_\varepsilon(t_0)\downarrow f(t_0)=-\infty$ and $f_\varepsilon(t)\downarrow f(t)$, so $f=-\infty$ on $B(t_0,r)$. This contradicts the fact that $\{f=-\infty\}$ is a null set. Hence $f$ is finite. Finally, every segment $[a,b]\subset V$ is compact and therefore lies in $V_\varepsilon$ for small $\varepsilon$; the convexity inequalities for $f_\varepsilon$ on $[a,b]$ pass to the pointwise limit, so $f$ is convex.

Conversely, let $f$ be a finite convex function on $V$. By \cref{prop:convex-local-regularity-and-subgradients}, $f$ is continuous and has a subgradient $p\in\mathbb R^n$ at every point. Let $w_0=t_0+\mathrm is_0$ be a point of the tube, $a\in\mathbb C^n\setminus\{0\}$, and $r>0$ such that the circle $\{w_0+r\mathrm e^{\mathrm i\theta}a:\theta\in[0,2\pi]\}$ lies in the tube. If $p$ is a subgradient of $f$ at $t_0$, then
\[
 f\bigl(\Real(w_0+r\mathrm e^{\mathrm i\theta}a)\bigr)
 \geq f(t_0)+r\left\langle p,
                       \Real(\mathrm e^{\mathrm i\theta}a)\right\rangle
 =f(t_0)+r\Real\Bigl(\mathrm e^{\mathrm i\theta}\sum_jp_ja_j\Bigr).
\]
The last term has mean zero over $\theta\in[0,2\pi]$, so the mean of the left side over the circle is at least $f(t_0)=f(\Real w_0)$. Since $w_0$, $a$ and $r$ are arbitrary, the restriction of the continuous function $f(\Real w)$ to every affine complex line satisfies the submean inequality of \cref{def:subharmonic} at every point, and it is therefore subharmonic. As $f(\Real w)$ is finite and continuous and the tube is a domain, \cref{def:plurisubharmonic} shows that $f(\Real w)$ is plurisubharmonic. It is invariant under imaginary translations by construction.
\end{proof}

\begin{corollary}\label{cor:toric-psh-finiteness}
Let $n\geq1$, let $V\subset\mathbb R^n$ be a nonempty open convex set, and put
\[
 \Omega_V=\{z\in(\mathbb C^*)^n:
                   (\log|z_1|^2,\ldots,\log|z_n|^2)\in V\}.
\]
Let $\varphi\in\PSH(\Omega_V)$ be invariant under the action of the compact torus $(S^1)^n$ by separate rotations of the coordinates, $(z_1,\ldots,z_n)\mapsto(\mathrm e^{\mathrm i\theta_1}z_1,\ldots,\mathrm e^{\mathrm i\theta_n}z_n)$. Then there is a finite convex function $f$ on $V$ such that
\[
 \varphi(z)=f(\log|z_1|^2,\ldots,\log|z_n|^2)\qquad(z\in\Omega_V).
\]
Conversely, for every finite convex function $f$ on $V$ this formula defines an $(S^1)^n$-invariant plurisubharmonic function on $\Omega_V$. In particular, an $(S^1)^n$-invariant plurisubharmonic function on $(\Delta^*)^n$ or on $(\mathbb C^*)^n$ is finite everywhere, where $\Delta^*=\{\zeta\in\mathbb C:0<|\zeta|<1\}$.
\end{corollary}
\begin{proof}
Consider the holomorphic map
\[
 E\colon\mathbb C^n\to(\mathbb C^*)^n,\qquad E(w)=(\exp(w_1/2),\ldots,\exp(w_n/2)).
\]
Since $\log|E_j(w)|^2=\Real w_j$, it maps the tube $V+\mathrm i\mathbb R^n$ onto $\Omega_V$; in particular, $\Omega_V$ is connected. By \cref{prop:psh-holomorphic-pullback}, $\varphi\circ E$ is either plurisubharmonic or identically $-\infty$ on the tube, and the second alternative is impossible because $E$ is surjective and $\varphi$ is nontrivial. Since $E(w+\mathrm is')=(\mathrm e^{\mathrm is_1'/2}E_1(w),\ldots,\mathrm e^{\mathrm is_n'/2}E_n(w))$, the rotation invariance of $\varphi$ makes $\varphi\circ E$ invariant under imaginary translations. \Cref{prop:invariant-psh-convexity} now gives a finite convex function $f$ with $\varphi(E(w))=f(\Real w)$, which is the asserted formula.

Conversely, let $f$ be finite and convex. Then $f(\Real w)$ is plurisubharmonic on the tube by \cref{prop:invariant-psh-convexity}. Near each point of $\Omega_V$, the map $E$ has the holomorphic local inverse $z\mapsto(2\log z_1,\ldots,2\log z_n)$, defined with local branches of the logarithm, and $f(\log|z_1|^2,\ldots,\log|z_n|^2)$ is the composition of $f(\Real w)$ with this inverse. By \cref{prop:psh-holomorphic-pullback} it is plurisubharmonic near that point, since it is finite. Plurisubharmonicity is a local property, so the function is plurisubharmonic on $\Omega_V$, and it is $(S^1)^n$-invariant because it depends only on $|z_1|,\ldots,|z_n|$. The domains $(\Delta^*)^n$ and $(\mathbb C^*)^n$ are $\Omega_V$ for $V=(-\infty,0)^n$ and $V=\mathbb R^n$. (In dimension zero, $(\mathbb C^*)^0$ is a point, and a plurisubharmonic function on it is a real number.)
\end{proof}
