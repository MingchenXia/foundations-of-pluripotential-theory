\chapter{Measures and distributions}
\label{chap:p01}
Let $\Omega$ be an open subset of $\mathbb R^d$, with $d\geq1$. Test functions define derivatives of singular potentials by integration; positivity connects these derivatives to measures.

\section{Test functions and distributions}
\label{sec:test-functions}
A test function on $\Omega$ is an element of $C_c^\infty(\Omega)$. For a nonempty compact set $K\subset\Omega$, write $\mathcal D_K(\Omega)$ for the test functions supported in $K$. A multi-index is an element $\alpha=(\alpha_1,\ldots,\alpha_d)\in\mathbb N^d$, with $|\alpha|=\alpha_1+\cdots+\alpha_d$. The seminorms on $\mathcal D_K(\Omega)$ are
\[
 p_{K,m}(\chi)=\max_{|\alpha|\leq m}\sup_{x\in K}|\partial^\alpha\chi(x)|,\qquad m\in\mathbb N.
\]

\begin{definition}\label{def:distribution}
A distribution\index{distribution} on $\Omega$ is a linear functional $T$ on $C_c^\infty(\Omega)$ such that, for each nonempty compact $K\subset\Omega$, there are $C>0$ and $m\in\mathbb N$ satisfying
\[
 |\langle T,\chi\rangle|\leq C p_{K,m}(\chi)\qquad\text{for all }\chi\in\mathcal D_K(\Omega).
\]
A distribution is real if it takes real values on real test functions. A real distribution is positive if $\langle T,\chi\rangle\geq0$ for every nonnegative real test function $\chi$.
\end{definition}
The constants $C$ and $m$ may depend on $K$. A locally integrable function $u$ defines a distribution by $\langle u,\chi\rangle=\int_\Omega u\chi\,\mathrm{d}x$: on $\mathcal D_K(\Omega)$ the bound holds with $m=0$ and $C=1+\int_K|u|\,\mathrm{d}x$.

For a multi-index $\alpha$, define the distributional derivative by
\[
 \langle\partial^\alpha T,\chi\rangle=(-1)^{|\alpha|}\langle T,\partial^\alpha\chi\rangle.
\]
The estimate for $T$ gives the distribution estimate for $\partial^\alpha T$ with order $m+|\alpha|$ on the same compact set. Integration by parts shows that this definition agrees with the classical derivative for smooth functions.
